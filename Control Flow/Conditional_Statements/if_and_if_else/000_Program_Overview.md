### 📌 Folder Overview

This folder contains **basic JavaScript programs** focused on **`if`, `else if`, and `else` conditional statements**. The programs demonstrate how conditions can be used to make decisions based on electricity consumption, calculate electricity bills, determine the number of days in a month, and apply discounts based on given conditions.

### 📌 Programs

| S.No. | Program Question                                                                                                                 | File Name               |
| ----: | -------------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
|     1 | Write a JavaScript program to calculate an electricity bill using an `if-else` statement based on the number of units consumed   | `B_electricity_bill.js` |
|     2 | Write a JavaScript program to find the number of days in a given month using `if-else` conditions                                | `days_in_month.js`      |
|     3 | Write a JavaScript program to calculate the discount amount based on the given purchase amount using `if-else` conditions        | `discount.js`           |
|     4 | Write a JavaScript program to calculate an electricity bill using `if-else` conditions based on different unit consumption slabs | `O_electricity_bill.js` |
