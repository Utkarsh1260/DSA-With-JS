### 📌 Folder Overview

This folder contains **basic JavaScript programs** focused on **`switch` statements** and **conditional logic**. The programs demonstrate how `switch-case` can be used to perform calculations, identify vowels and consonants, and handle different cases based on user input.

### 📌 Programs

| S.No. | Program Question                                                                                                   | File Name                    |
| ----: | ------------------------------------------------------------------------------------------------------------------ | ---------------------------- |
|     1 | Write a JavaScript program to perform different operations using a switch statement based on the selected operator | `calculator_switch.js`       |
|     2 | Write a JavaScript program to check whether a given character is a vowel or consonant using a switch statement     | `vowel_consonant.js`         |
|     3 | Write a JavaScript program to count the number of vowels and consonants in a given string using a switch statement | `count_vowels_consonants.js` |
|     4 | Write a JavaScript program to identify the area of different shapes using a switch statement                       | `area_switch.js`             |
