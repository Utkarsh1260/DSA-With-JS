### 📌 Folder Overview

This folder contains **basic JavaScript programs** focused on **number-based logical problems, loops, and conditional statements**. It demonstrates how to manipulate numbers, extract digits, perform mathematical calculations, and apply conditions to solve common programming problems.

### 📌 Programs

| S.No. | Program Question                                                                                  | File Name               |
| ----: | ------------------------------------------------------------------------------------------------- | ----------------------- |
|     1 | Write a JavaScript program to reverse a number                                                    | `reverse_number.js`     |
|     2 | Write a JavaScript program to check whether the given input is an Automorphic Number or not       | `Automorphic_Number.js` |
|     3 | Write a JavaScript program to check whether the given number is a valid ISBN-10 or ISBN-13 or not | `valid_ISBN_number.js`  |
