### 📌 Folder Overview

This folder contains **basic JavaScript programs** covering different types of **loops and loop control statements**. It demonstrates how to repeat code using `for`, `while`, `do...while`, `for...of`, and `for...in` loops. It also includes programs demonstrating **`break` and `continue`**, which are used to control the execution of loops.
